# Точка ремонта

Адаптивный сайт-концепция сервиса по ремонту бытовой техники. Палитра: молочная, терракотовая, графитовая и приглушённая зелёная.

## Возможности

- Фильтры по типу техники и подробные карточки.
- Сравнение стоимости ремонта и покупки новой техники.
- Частые вопросы и мобильное меню.
- Подготовка обращения в браузере, копирование и скачивание текста.

Форма не отправляет заявки и не сохраняет персональные данные на сервере. Перед коммерческим запуском нужно указать реальные контакты, территорию обслуживания, условия работы и подключить согласованный канал доставки заявок.

## Публикация на GitHub Pages

Сайт не требует сборки. В настройках репозитория: **Settings → Pages → Deploy from a branch → main → / (root) → Save**. После завершения публикации адрес появится в разделе Pages.

## Локальный просмотр

Откройте `index.html` в браузере или запустите любой статический HTTP-сервер в корне проекта. `styles.css`, `app.js`, `appliances.svg` и `favicon.svg` должны лежать рядом с `index.html`.

Шрифт Manrope загружается с Google Fonts; предусмотрен системный резервный шрифт. Иллюстрация и иконки находятся в проекте. Серверная часть, сторонние ключи и зависимости не нужны.
